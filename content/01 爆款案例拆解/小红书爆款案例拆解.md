小红书图文赛道的爆款观察。基于个人账号多赛道实战（数码测评、宠物、BJD潮玩、二次元文娱）与搜索流量逻辑，拆解图文爆款的可复制结构。

## 小红书流量双逻辑

### 1. 推荐流量

- 封面+标题决定首屏点击率
- 内容互动（赞藏评）驱动推荐加权
- 图文质量与完读率影响后续流量池

### 2. 搜索流量

- 小红书是**搜索型内容平台**：用户带着问题来，搜索排名=长尾流量
- 选题踩中搜索词（痛点/疑问/教程类），单篇可长期获流
- 个人实战：数码测评类内容踩中搜索流量，单篇笔记最高浏览 2061

## 爆款图文结构：痛点开头 + 干货正文 + 互动结尾

### 开头：抓住"与我有关"

- 直接点出用户痛点或使用场景
- 用具体场景引发代入感，避免空泛开场

### 正文：结构化干货

- 分点/分步呈现，信息密度高
- 图片配图贴合阅读习惯：实拍、对比图、标注清晰
- 保持口语化表达，降低阅读门槛

### 结尾：引导互动

- 提问式结尾：邀请评论区补充/讨论
- 话题标签策略：垂类标签 + 场景标签组合

## 标签与发布策略

| 要素 | 做法 |
| --- | --- |
| 标签 | 垂类标签 + 场景/人群标签组合，覆盖搜索词 |
| 发布时间 | 贴合目标用户活跃时段 |
| 更新节奏 | 稳定频率养账号权重，观察赛道流量差异 |

## 案例拆解示例

### 案例A：数码测评笔记（搜索流量型）

| 维度 | 拆解 |
| --- | --- |
| 选题 | 踩中搜索词：产品痛点/选购疑问 |
| 标题 | 点明问题+给出结论倾向 |
| 封面 | 实物图 + 核心卖点文字标注 |
| 正文 | 分点对比，干货密度高 |
| 数据 | 单篇最高浏览 2061，搜索流量占比高 |

### 案例B：宠物/潮玩内容（推荐流量型）

| 维度 | 拆解 |
| --- | --- |
| 选题 | 萌点/情绪价值向，封面即内容 |
| 封面 | 高颜值实拍，一眼触发点击 |
| 正文 | 短段落 + 多图，互动结尾 |
| 数据 | 互动率（赞藏）表现稳定，利于推荐加权 |

## 可复用结论

- **搜索向内容**收益可累积：单篇笔记的搜索长尾能持续带来浏览
- 多赛道测试可验证流量逻辑：用数据对比不同品类的表现，再确定主攻垂类
- 图文爆款 = 搜索词命中 × 封面点击率 × 干货留存 × 互动引导
