选题评估模板，用于内容策划阶段快速筛选高潜力选题。基于 B站、小红书实战验证的「用户兴趣 × 内容稀缺性 × 传播潜力」三维评估框架。

## 评估框架

对每个候选选题按三个维度打分（1-5分），总分 ≥ 10 分建议立项。

| 维度 | 评估问题 | 得分(1-5) |
| --- | --- | --- |
| 用户兴趣 | 目标受众是否真的关心？是否有讨论热度/搜索需求？ | |
| 内容稀缺性 | 同赛道已有内容是否饱和？本选题是否有差异化角度？ | |
| 传播潜力 | 是否具备传播点（情绪价值/实用价值/社交货币）？ | |
| 调性匹配 | 是否契合账号人设与内容方向？ | |

## 选题构思清单

### B站视频选题

- [ ] 是否基于热门 IP / 高热度题材？
- [ ] 是否有明确的情绪价值或看点（名场面/高能片段/争议点）？
- [ ] 同赛道爆款是否验证过该方向？
- [ ] 标题与封面是否有差异化切入点？

### 小红书图文选题

- [ ] 是否踩中搜索词（痛点/疑问/教程类）？
- [ ] 封面是否有点击吸引力？
- [ ] 是否有干货密度，值得收藏？
- [ ] 结尾是否设置互动引导？

## 使用说明

1. 每周收集同赛道热门内容，拆解后录入选题池
2. 批量评估候选选题，标注得分与选题依据
3. 发布后回到 [[03 模板沉淀/内容复盘模板|内容复盘模板]] 验证选题判断，持续校准框架
