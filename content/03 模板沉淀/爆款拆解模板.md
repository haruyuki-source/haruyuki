爆款拆解模板，用于观察平台热门内容时快速结构化记录，沉淀可复用的爆款思路。适配 B站视频、小红书图文等不同内容形态。

## 拆解步骤

### 1. 基本信息

| 项目 | 内容 |
| --- | --- |
| 平台 | B站 / 小红书 / 其他 |
| 内容标题 | |
| 作者/账号 | |
| 数据表现 | 播放/浏览、点赞、收藏、评论、弹幕 |
| 发布时间 | |

### 2. 内容拆解

**选题**：主题是什么？踩中什么热点/搜索词/用户痛点？

**结构**：开头钩子是什么？正文如何组织（分点/叙事/对比）？

**标题封面**：标题用了什么手法（悬念/数字/反差）？封面有什么视觉冲击点？

**互动设计**：内容中埋了什么讨论点？结尾如何引导互动？

### 3. 爆款归因

结合数据判断爆款主因（可多选）：

- [ ] 选题踩中热点/搜索需求
- [ ] 开头钩子强，完读/完播率高
- [ ] 标题封面点击率高
- [ ] 情绪价值/实用价值突出
- [ ] 讨论点设置引发互动
- [ ] 发布时机好

### 4. 可迁移结论

- 这条内容的方法能迁移到哪些选题方向？
- 哪些做法可纳入自己的内容 SOP？

## 使用建议

- 每周固定拆解 3-5 条，形成「爆款思路库」
- 同赛道拆解积累到一定量后，归纳共性规律（参考 [[01 爆款案例拆解/B站爆款案例拆解|B站爆款案例拆解]]）
- 拆解结论反哺 [[03 模板沉淀/选题评估模板|选题评估]]
